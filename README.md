# Alpha Dashboard

Admin dashboard built with React + Vite.

## Features

- Authentication & RBAC
- Product Listing
- Product Detail Page
- Analytics Dashboard
- Search
- Multi Category Filtering
- Sorting
- Pagination
- URL State Synchronization
- Debounced Search
- React.memo
- useMemo
- useCallback
- Lazy Loading

## Tech Stack

- React
- React Router
- React Query
- Zustand
- Vite

## Run Locally

npm install

npm run dev
